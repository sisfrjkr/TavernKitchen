# TavernKitchen v2.2 — «Ведьмачья Похлёбка»

Уютный симулятор таверны на **Godot 4.7** (GDScript, Compatibility-рендерер — подходит для веб-сборки Яндекс Игр и мобильных).

## Как запустить

1. Откройте папку проекта в Godot 4.7 (`project.godot`).
2. **При первом открытии дождитесь импорта ресурсов** (картинки, звуки, шрифт) — внизу справа идёт полоска прогресса. Без импорта игра запустится, но без графики интерфейса и без звука.
3. Нажмите F5.

Управление: мышь или касание. `Esc` — настройки/закрыть окно.

## Разнообразие (v2.7)
Книга рецептов, секретные сочетания, особые заказы, вкусы гостей, блюдо дня — см. `docs/V2_7_NOTES.md`.

## Прогрессия (v2.9)
Ежедневные цели, достижения, книга таверны (гости), обучение — см. `docs/V2_9_NOTES.md`.

## Звук (v3.0)
Многослойная атмосфера таверны, позиционные голоса посетителей, 7 шин, 4 музыкальные темы, 5 ползунков громкости — см. `docs/AUDIO.md`.

## Этапы таверны, веб (v3.1)
Три визуальных этапа (скромная → популярная → известная), награда рекламы «редкие ингредиенты на завтра», пресет веб-экспорта — см. `docs/V3_1_NOTES.md`, `docs/WEB_EXPORT.md`, `docs/PERFORMANCE.md`.

## 3D-реквизит
Вместо стопок примитивов используются 58 low-poly моделей `assets/models/*.glb` (см. `docs/MODELS.md`); их можно заменять своими с теми же именами.

## Как играть

Гость делает заказ → выберите **основу** → **продукт** → **траву** (можно вторую — «по желанию») → «Готовить». Во время варки можно «Помешать» (ускоряет). Результат: идеально / подходит / не то — с объяснением, почему. Заработанные монеты тратятся в магазине на восемь улучшений, каждое из которых видно в таверне и/или влияет на игру.

В настройках: отдельная громкость музыки и звуков, «Расслабленный режим» (гости не теряют терпение).

## Тесты

```
godot --headless --path . --import          # один раз, чтобы зарегистрировать классы
godot --headless --path . -s tests/run_all.gd
```
Код выхода 0 — всё прошло. Тесты не требуют сцен и проверяют: оценку блюд, экономику, достижимость «идеально» для каждого заказа, полный игровой день, потерю заказа, покупки и перезапуск с сохранением, повреждённые/старые сохранения.

Дымовой тест настоящей игры (4 дня через интерфейс): `godot --path . -s tests/smoke_game.gd` — см. `docs/BUGS_AND_TESTING.md`.

Статическая проверка без Godot: `python3 tools/lint_gd.py`. Офлайн-проверка камеры/пустоты/перекрытий интерфейса: `python3 tools/preview_scene.py` (см. `docs/V2_2_1_NOTES.md`).

## Структура

```
scripts/domain/        чистые данные и правила (заказы, оценка, гости, улучшения, SaveData)
scripts/services/      игровой цикл (GameSessionService), сохранения, звук, реклама, экономика
scripts/presentation/  GameScreen, Tavern (3D-диорама), Kitchen (котёл), UiKit, Localization
scripts/ui/            виджеты: карточки, лоток ингредиентов, панели результата/итогов/магазина/меню
assets/                иконки, портреты гостей, UI-текстуры, 3D-текстуры, звуки, шрифт
tools/                 генераторы всех ассетов (Python: Pillow, numpy, scipy, ffmpeg)
tests/                 unit-тесты
```

Все ассеты оригинальные и созданы кодом (`tools/gen_*.py`), их можно перегенерировать и заменить своими с теми же именами файлов. Шрифт Lora — SIL Open Font License.

## Реклама (Яндекс Игры)

SDK **не подключён**. Есть интерфейс `RewardAdProvider` и сервис `RewardAd`. Пока провайдер не зарегистрирован, кнопка рекламы скрыта, игра работает без ошибок. Когда будете подключать SDK веб-сборки, напишите наследника `RewardAdProvider` (`is_ready()`, `show(on_rewarded, on_closed, on_error)`) и вызовите `RewardAd.register_provider(...)`. Награда («удвоить заработок дня») выдаётся только из колбэка `on_rewarded`.

## Сохранения

`user://tavern_kitchen/save.cfg` (+ `.bak`). Запись атомарная, повреждённый файл не роняет игру (берётся копия или начинается новая игра). Версия формата 3; старые сохранения мигрируют (удалённые улучшения возвращают монеты).
Сохраняется прогресс на уровне «конец заказа / конец дня»; середина заказа при выходе не восстанавливается.
