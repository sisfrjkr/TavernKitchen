# Баги, диагностика и проверка (v3.2)

## Исправлено в v3.2
- **Начальные кнопки налезали на другие экраны.** Главное меню рисовалось ПОВЕРХ окон (настройки/магазин/книги), открытых из меню
  (порядок узлов в `GameScreen`). Теперь порядок: 3D → виньетка → HUD → меню → окна → обучение; при показе меню все окна
  закрываются (`_close_all_overlays`).

## «Вылет на втором дне» — не воспроизведён, нужна ваша помощь
В среде разработки нет Godot, поэтому прямой причины я доказать не смог. Что сделано:
1. Проверен код перехода дня (итоги → «Следующий день» → новые цели/заказ → гость во второй визит: реплика приветствия,
   блюдо дня, цели, достижения, смена музыки на вечернюю и обратно) — явных ошибок не найдено.
2. Добавлен **дымовой тест реальной игры** `tests/smoke_game.gd`: загружает главную сцену, нажимает карточки как игрок,
   готовит, теряет заказ, проходит 4 дня, открывает все окна, покупает улучшения. Он сам покажет, где и какая ошибка:
   `godot --path . -s tests/smoke_game.gd` (используется отдельное сохранение, ваш прогресс не трогается).
3. Включена запись логов: ошибки теперь сохраняются в `user://logs/godot.log`
   (Windows: `%APPDATA%\Godot\app_userdata\TavernKitchen\logs\godot.log`; из редактора: Project → Open User Data Folder).

**Пришлите, пожалуйста:** (а) вывод `smoke_game.gd` или (б) красные строки из панели «Отладчик → Ошибки» либо `godot.log` в момент вылета —
с этим я исправлю причину точно. Полезно также: на каком действии вылетает (кнопка «Следующий день»? первый заказ? открытие магазина?).

## Что делать при вылете
Если игра остановилась на красной ошибке в редакторе — это ошибка скрипта (в экспортированной версии игра продолжила бы работу).
Скопируйте текст ошибки целиком, включая стек вызовов (строки вида `at: ... (файл.gd:123)`).
