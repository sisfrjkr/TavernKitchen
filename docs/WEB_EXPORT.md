# Веб-экспорт (HTML5) и подготовка к Яндекс Играм

> Экспорт в этой среде не выполнялся (нет Godot и шаблонов экспорта). Ниже — настройки и чек-лист, которые нужно пройти у себя.

## Настройки, которые уже сделаны в проекте
- Рендерер **Compatibility** (`gl_compatibility`) — единственный вариант для веба и слабых телефонов.
- `export_presets.cfg` с пресетом **Web**: **без потоков** (`thread_support=false`: не нужны заголовки SharedArrayBuffer, игра
  работает во фрейме), без расширений, папка вывода `build/web/index.html`, из экспорта исключены `tools/`, `docs/`, `tests/`.
  Если Godot ругается на файл пресетов, пересоздайте его: Project → Export → Add… → Web, отключите Thread Support.
- Растяжение `canvas_items`, `expand`: интерфейс сам переключается между 1280×720 и 720×1280.
- Сохранения идут в `user://` (в браузере это IndexedDB); запись атомарная, повреждение не роняет игру.

## Как собрать
1. Godot 4.7 → Editor → Manage Export Templates → установите шаблоны.
2. `./tools/export_web.sh` (или Project → Export → Web → Export Project).
3. Локальный тест: `python3 -m http.server -d build/web 8000` и откройте http://localhost:8000 (файл:// не работает).

## Чек-лист перед публикацией
- [ ] Консоль браузера без ошибок и предупреждений о ресурсах (F12 → Console).
- [ ] Загрузка ≤ нескольких секунд: размер `.pck` + `.wasm`. Ресурсы игры ≈ 4.5 МБ (см. `docs/PERFORMANCE.md`); основной вес — ядро Godot (~35–40 МБ wasm до сжатия).
- [ ] Мышь и касание; поворот телефона; нет прокрутки страницы.
- [ ] Сохранение переживает перезагрузку страницы.
- [ ] Звук стартует только после первого касания (требование браузера) — музыка меню включится после нажатия «Играть»/клика.
- [ ] Реклама: SDK Яндекс Игр **не подключён намеренно**. Для подключения напишите наследника `RewardAdProvider`
  (`is_ready()`, `show(on_rewarded, on_closed, on_error)`) по документации SDK и вызовите `RewardAd.register_provider(...)`.
  Награды (удвоение заработка дня, редкие ингредиенты на завтра) выдаются только из колбэка `on_rewarded`.
  Без провайдера кнопки рекламы скрыты, игра работает.
